## Structures and labor

- A territory's **rating** for a resource sets the rate at which a structure built there can
  extract it
- For example, a territory can have a **food rating** of 8, which means if a **farm** is
  constructed there, each **turn** a **citizen** may expend **labor** to generate an amount
  of **food** equal to that rating
