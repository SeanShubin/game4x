The whole specification as formulas

Every recipe re-expressed in six primitives — and the same six building the world from an empty game. Generated from tools/research/formulas/data.json.

The one finding

Creation and transformation are already the same format, because the specification has been quietly turning relations into things. deposit and adjacency are kinds. Once a relation is a thing, building the world is create and set with no thresholds — the identical primitives that play the game. Nothing needs adding for world-building except the set that transformation needed anyway.

The primitives

Six. set is the one the sketch was missing, and it is what collapses age and refresh from two rows to one each.

Primitive What it does Example Why it earns a place
create Bring a thing into being, of a kind, inside a container create garrison in t the only way anything begins to exist
destroy Remove an identified thing destroy ark the only way anything stops existing
set Assign a trait on an identified thing set extractor.ready = no the primitive the sketch was missing
threshold A guard: a count against a bound, in a direction garrison in t at most 0 the only thing that can refuse
attach Whether failing a guard fails the action, or skips its own line hard / soft Sean's fail-behavior
call Apply another formula with arguments call found-colony(t) the hierarchy

What is sugar

Removable with linear growth, so by the test each is readability rather than expressiveness — which means they can be added freely.

Written as Means Cost of removing it
change(k, +n) n creates linear - readability only
change(k, -n) n destroys linear - readability only
let x = path substitute the path at each use linear - readability only
consume n k threshold(k, at least n, hard) then n destroys linear
require n k threshold(k, at least n, hard) exact
produce n k n creates exact
limit n k threshold(k, at most n, hard) exact

What the re-encoding cost and saved

Computed from the data rather than asserted. In bare primitives, 58 rows became 68 lines — up 10. That is the number predicted before any of this was written, and it is the misleading one.

Almost all of the rise is one thing: today's consume fuses a guard and an effect, and splitting it costs a line each time. There are 15 such pairs. Since consume is sugar — it is in the table above — an author never has to write both, and the authored count is 53 lines, down 5 from 58.

So which number is real

All three, measuring different things. Up 10 is what the machine executes. Down 5 is what a person writes. And the one that matters is neither: the vocabulary went from four roles that could not name create-if-missing to six primitives that also build the world from nothing. A count of lines cannot see that, which is the whole reason to fix the metric first.

Decisions this forced, none of them taken here

Question What is at stake How it shows up
The garrison threshold in found-colony: hard or soft? Hard is today's rule and refuses the whole action. Soft is the sketch, and then a second deploy adds 2 citizens, 2 extractors and 2 stores to an existing colony. If soft, each of the six creates needs its own threshold, and they are not the same answer.
Do the sketch's missing stores come back? The sketch creates a garrison, 2 citizens and 2 extractors. The specification also creates a food store and a metal store. Dropping them changes the game.
Does composition see the starting state or the running one? Each line applied can mean every line reads the state as it was, or each reads the effects of the ones before it. grow consumes food and creates citizens; work destroys labor and creates a resource. Any recipe touching one thing twice will tell them apart.
Does a thing have identity, or is it a count? set requires an identified thing. destroy ark means this ark. create citizen 2 means two more, with no identity asked for. The dump already answers this: nine of its ten tables are the containment tree of identified things.
Is extractor capacity a threshold on the recipe, or a property of the container? build extractor now needs an explicit at most capacity - 1 threshold, which the current table left implicit in Where things are. Making it explicit is more rows. Leaving it implicit means the engine enforces something no formula states.
