A food extractor and a metal extractor, two labor, and the food one still works only once.

Sean, 2026-09-17: *Will this still work if we have 1 food extractor and 1 metal extractor and
2 labor? I don't want be able to run the food extractor twice.*

An allowance is keyed like the thing that has it - (where, what), the same key as
extractor - so the metal extractor's readiness is a different row and is no use to the food
one. Everything the second command needs except the readiness is present: there is labor for
it, a deposit under it, and an extractor to do it, which is what makes this about the key.

{test name:one-extractors-readiness-is-not-anothers}

{given}
{territory id:1 name:territory-1}
{place id:1 of:territory-1 layer:surface name:place-1}
{capacity of:deposit for:extractor what:resource per:place} -> 1
{deposit where:place-1 what:food density:6} -> 1
{deposit where:place-1 what:metal density:2} -> 1
{extractor where:place-1 what:food working:1} -> 1
{extractor where:place-1 what:metal working:1} -> 1
{labor where:place-1} -> 2

{when}
{work where:place-1 what:food}
{work where:place-1 what:food}

{refused}
