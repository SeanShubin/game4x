One deposit, already holding an extractor, and a second extractor has nowhere to stand.

No rule refuses this. build-extractor adds the extractor and the world it would leave does
not fit, which is where the refusal comes from - so the limit holds for every rule that makes an
extractor, including ones not written yet.

The refusal names what would have had to be there: a deposit with room for two.
